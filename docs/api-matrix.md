## API policy

The client sends `X-GitHub-Api-Version: 2026-03-10` to GitHub.com and retains
the broadly compatible `2022-11-28` contract for GitHub Enterprise Server.
GitHub Enterprise Server requests always remain on the configured `/api/v3`
origin and never route to `api.github.com`.

No documented public endpoint was identified for exact live Copilot
conversation/token details, universal remaining Copilot quota, future invoices,
or retroactive per-workflow billed cost. Those rows are intentionally absent
rather than backed by scraping or internal APIs.
