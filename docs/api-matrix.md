## API policy

The client sends the current supported `X-GitHub-Api-Version` selected during
implementation, records it in sanitized diagnostics, and does not assume the
documentation URL's version query matches the current rendered API examples.
GitHub Enterprise Server capability discovery must use its own advertised
version and never route enterprise URLs to `api.github.com`.

No documented public endpoint was identified for exact live Copilot
conversation/token details, universal remaining Copilot quota, future invoices,
or retroactive per-workflow billed cost. Those rows are intentionally absent
rather than backed by scraping or internal APIs.
